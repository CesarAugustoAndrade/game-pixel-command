# Assets Directory

This directory contains all game assets including sprites, sounds, and data files.

## Directory Structure

### sprites/
- **units/** - Unit sprites for all factions
- **terrain/** - Terrain tile sprites (plains, hills, forest, etc.)
- **ui/** - UI elements (buttons, panels, icons)

### sounds/
- Sound effects for combat, movement, UI interactions

### music/
- Background music tracks for different game states

### data/
- JSON configuration files for units, factions, abilities, etc.

## Asset Guidelines

### Sprites
- Unit sprites: 32x32 pixels (or multiples)
- Terrain tiles: Match hex size (32x32)
- Use consistent art style (pixel art recommended)
- PNG format with transparency

### Sounds
- Format: OGG or WAV
- Keep file sizes reasonable
- Consistent volume levels

### Music
- Format: OGG recommended
- Loop-friendly tracks
- Separate tracks for menu, battle, victory, defeat
